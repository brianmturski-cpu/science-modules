# science-modules

Interactive science modules, 3D animations and project manuals for Mr. Brian's classes.
Each one is a single offline HTML page. They are hosted on GitHub Pages:

**Homepage:** https://brianmturski-cpu.github.io/science-modules/

## Layout

| Folder | What it holds |
| --- | --- |
| `index.html` | Homepage that links every module, grouped by course |
| `bio-7-8/` | 7th & 8th grade Biology modules, one folder per block (`2.4-diffusion-osmosis/`, `2.5-active-transport/`, `3.2-light-reactions/`) |
| `earth-6/` | 6th grade Earth & Space modules (`convection-tank/`) |
| `engineering/` | Autodesk Fusion build instructions (`fin-heat-sink/`, `hose-barb/`) |
| `cell-research-project/` | 7/8 Cell Research Project manual (live link, do not move) |
| `museum-project/` | 6th grade Museum of a Moving Planet manual (live link, do not move) |
| `block-3.2/` and the old `.html` files at the top level | Redirects only. They forward old links to the new locations. |

## Adding a module

1. Make a folder under the course, named `<block>-<short-topic>` in lowercase with hyphens, e.g. `bio-7-8/3.3-calvin-cycle/`.
2. Put the module in it as `index.html` (extra pages, like a second animation, go next to it).
3. Add a card for it to the homepage `index.html`.

Short folder names give students short links, e.g. `.../science-modules/bio-7-8/3.3-calvin-cycle/`.
